Modes 05
3 façons de travailler avec MLflow
LOCAL
UI: http://localhost:5000
  • Installation simple, sans service séparé à lancer
  • Organiser les runs d’exploration facilement
  • UI locale immédiate
  • Idéal pour prise en main, POC et démo offline
POC solo, apprentissage, démo offline.
SERVEUR
UI: http://<host>:<port>
  • Déploiement simple via Docker Compose
  • MLflow + PostgreSQL gérés dans la stack
  • Runs visibles par toute l’équipe
  • Registry partagée
Formation de groupe, projets d’équipe, partage des runs.
DATABRICKS
UI: https://<workspace>
  • Workspace managé Azure Databricks
  • Unity Catalog et gouvernance
  • Serving natif + scaling
  • Monitoring drift données et performance modèle
Production, gouvernance, contexte client ou plateforme.
